# 한국어 학교 — Виртуальная школа корейского языка

Проектная документация образовательной среды для русскоязычных учеников: от нуля (Хангыль) до TOPIK 6급.

Главная идея: не набор мини-игр, а **школа**. Ученик поступает в класс, ходит на «уроки» по расписанию, сдаёт контрольные, ведёт тетрадь ошибок и переводится в следующий класс, только когда реально освоил текущий.

## Коротко о системе

```
                 ┌──────────────── Вступительный тест (адаптивный) ────────────────┐
                 ▼                                                                 │
  0급 Подготовительный ─► 1–2급 Начальная ─► 3–4급 Средняя ─► 5–6급 Старшая ─► Выпуск
  (Хангыль, фонетика)     (TOPIK I)           (TOPIK II)        (TOPIK II)
        │                     │                   │                 │
        └──── в каждом 급: 2 семестра × (중간고사 + 기말고사) → 졸업시험 (симуляция TOPIK) ────┘

  Каждый день:  조회 (повторение) → 1교시 (новое) → 2교시 (ввод) → 3교시 (вывод) → 종례 (오답노트)
  Всегда рядом: словарь с разбором · карточки FSRS · библиотека · грамматический справочник · клубы
```

Четыре опоры, на которых держится всё:

1. **Баланс «четырёх потоков» (Nation)**: примерно поровну понятного ввода, говорения и письма, работы над формой и тренировки беглости.
2. **Полное усвоение (Mastery Learning)**: следующий шаг открывается после 80% на контрольной, а провал ведёт на доработку, а не в тупик.
3. **Память под управлением алгоритма**: FSRS для слов, грамматики и ханча. Всё, что ученик видел, вернётся к нему вовремя.
4. **Спираль**: темы (семья, еда, работа, общество…) возвращаются на каждом уровне с новым словарём и другим стилем речи.

## Приложение (версия 0.3)

Веб-приложение на React + TypeScript + Vite. Работает в браузере и на телефоне (можно добавить на главный экран как PWA).

Что уже есть:
- **Зачисление** в 예비반 и **кампус** с картой школы: окна здания загораются по мере прохождения уроков.
- **Генератор учебного дня** (`src/lib/plan.ts`): 조회 → 1교시 → 2교시 → 쉬는 시간 → 종례 из реального состояния ученика.
- **Курс 0급 (Хангыль)**: 6 уроков в 3 юнитах — гласные, согласные и три ряда, слоговой блок, патчим.
- **Движок уроков** с шагами: доска с правилом, диалог, карточки букв с озвучкой, выбор (в т.ч. на слух), конструктор слога, сборка из блоков.
- **Карточки FSRS** (`ts-fsrs`): слова урока автоматически становятся карточками КР→РУ и РУ→КР, лимит 10 новых в день.
- **오답노트**: ошибки записываются сами, запись закрывается после 3 верных ответов в разные дни.
- **Переводной экзамен 예비반** (`src/content/exams/prep.ts`): 25 заданий (듣기, 읽기, диктант), 20 минут, зачёт от 80%. Каждая попытка — новый вариант из банков заданий. Провал → разбор ошибок → 보충수업 → пересдача. Сдача переводит в 1급. Экзамен можно сдать экстерном из программы класса.
- **Курс 1급 целиком**: 10 юнитов, 23 урока — связка 이에요/예요, 은/는, 이/가 아니에요, 이거/그거/저거, 있어요/없어요, 의 и семья, -아/어요, 을/를, 에/에서, сино-корейские числа и цены, исконные числа и счётные слова, время, прошедшее -았/었어요, отрицание 안/-지 않아요/못, будущее -(으)ㄹ 거예요, -고 싶어요, просьбы -(으)세요, -(으)ㄹ까요/-(으)ㅂ시다, стиль -습니다/-ㅂ니다, чтение объявления.
- **Переводной экзамен 1급 в формате TOPIK I** (`src/content/exams/topik1.ts`): 듣기 15 + 읽기 20 заданий тех же типов, что на настоящем TOPIK I (ответ на вопрос, реплика, место, тема, соответствие; тема текста, пропуск, объявление, содержание, главная мысль), 45 минут, результат по шкале 200, зачёт от 140 и оценка уровня по порогам настоящего экзамена.
- **Движки форм** — `lib/conjugate.ts` (해요체, прошедшее, 합니다, -(으)세요, -(으)ㄹ 거예요, -(으)ㄹ까요, -고 싶어요, отрицания; нерегулярные ㅂ ㄷ ㅅ ㅎ 르 и ㄹ-основы) и `lib/numbers.ts` (сино-корейские и исконные числа, счётные формы, время, цены, телефоны): задания генерируются, а не пишутся руками.
- Превью урока 2급 «-아/어서 и -(으)니까» из прототипа.

### Запуск

```bash
npm install
npm run dev        # разработка
npm test           # тесты логики и проверка контента
npm run build      # сборка в dist/
```

### Структура

```
src/
  content/        учебный контент: типы, каталог классов, уроки по 급
  lib/            hangul (сборка слогов), srs (FSRS), notebook (오답노트), plan (учебный день), sound
  state/store.ts  состояние ученика (zustand, хранится в localStorage)
  features/       экраны: campus, lesson (+ steps), cards, notebook
  components/     общие компоненты: TabBar, Rich (мини-разметка контента), toast
prototype/        исходный кликабельный прототип
```

Новый урок — это объект `Lesson` в `src/content/gradeN/` и строка в `src/content/catalog.ts`. Тесты `catalog.test.ts` проверяют, что ответы существуют, а слоги собираются из палитры.
