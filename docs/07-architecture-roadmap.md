# 7. Архитектура, данные и план запуска

## 7.1. Технический стек (предложение)

| Слой | Выбор | Почему |
|------|-------|--------|
| Мобильный клиент | **Flutter** или **React Native (Expo)** | Один код на iOS / Android / веб; кастомная анимация (Rive / Lottie) для «живого» интерфейса |
| Оффлайн | Локальная БД (SQLite / Drift) + синхронизация | Карточки FSRS и загруженные уроки работают без сети (метро) |
| FSRS | Открытые реализации (`fsrs-rs`, `ts-fsrs`, `py-fsrs`) | На клиенте — расписание, на сервере — оптимизация параметров |
| Бэкенд | **PostgreSQL** + API (Node/TypeScript или Python FastAPI) | Реляционные связи: слово ↔ урок ↔ ханча ↔ текст |
| Морфология | **Kiwi** (kiwipiepy, открытый, качественный) / MeCab-ko | Разбор словоформ, лемматизация текстов библиотеки |
| Поиск | Meilisearch / OpenSearch с корейским анализатором | Словарь, корпусный поиск примеров |
| Речь | ASR: Whisper / облачный корейский ASR; TTS: облачные нейро-голоса + **записи носителей** для ядра 6000 слов | Оценка произношения через forced alignment |
| ИИ | LLM через API (проверка, диалоги, оценка эссе) | Строго структурированный вывод (JSON), кэш, лимиты стоимости |
| Аналитика | Событийная (PostHog / собственная) + хранилище для IRT/FSRS-оптимизации | |

## 7.2. Модель данных (ядро)

```
Level (급) ─┬─ Semester ─┬─ Unit ─┬─ Lesson ─┬─ Exercise
            │            │        │          ├─ uses → GrammarPoint
            │            │        │          └─ uses → Lexeme
            │            ├─ Exam (midterm/final/promotion) ─ ExamItem (IRT: a, b)
            │
Lexeme (лемма, POS, уровень NIKL, частотность)
  ├─ Sense (значение, перевод RU, примеры)
  ├─ HanjaRoot[] (многие-ко-многим)
  ├─ Pronunciation (IPA-подобная запись, аудио)
  └─ Conjugation (тип нерегулярности)

GrammarPoint (форма, значение, уровень, категория смысла, ограничения)
  └─ Contrast (пары/группы для сравнения)

Text (библиотека: уровень, жанр, лицензия)
  ├─ Sentence (KR, RU, аудио-таймкоды)
  └─ TokenIndex (лемма, позиция, грамматика) → coverage

Learner
  ├─ CardState (card_id, D, S, last_review, due, direction)
  ├─ ReviewLog (для оптимизации FSRS)
  ├─ GrammarState (P_mastery, stability)
  ├─ SkillEstimate (skill, θ, se)
  ├─ ErrorNote (오답노트: type, context, fix, rule_id, status)
  ├─ Attendance, Grades, ExamAttempt
  └─ Class (반) membership, Clubs
```

## 7.3. Источники контента и лицензии

| Контент | Источник | Замечания |
|---------|----------|-----------|
| Словарь | **한국어기초사전** (NIKL): ~50 000 статей, переводы на русский | Открытая лицензия (CC BY-SA 2.0 KR), требует атрибуции и редактуры перевода |
| Лексические уровни | 한국어 학습용 어휘 목록 (NIKL) | Публичный список |
| Грамматика | Стандарт NIKL + собственные объяснения на русском | Объяснения пишем сами (*Korean Grammar in Use* — только ориентир, не копируем) |
| Сказки, классика | 전래동화, авторы в общественном достоянии (умершие > 70 лет назад: 김소월, 현진건, 김유정, 이상, 나도향) | Адаптацию по уровням делаем сами |
| Graded readers | **Собственное производство**: авторы-носители + редактура + озвучка | Главный уникальный актив продукта |
| Новости, вебтуны, дорамы | Только по **лицензионным соглашениям** (платформы, издатели) | Без лицензии — только собственные «сцены в стиле…» и короткие цитаты в рамках добросовестного использования. Юридическая проверка обязательна |
| Задания TOPIK | Официальные прошлые варианты публикуются NIIED | Использование — по условиям NIIED; основной банк — **собственные задания в формате TOPIK** |
| Аудио | Студийная запись носителей (ядро) + нейро-TTS (остальное) | |

**Контент — основной объём работы.** Ориентировочно: ~700 уроков, ~10 000 упражнений-шаблонов, ~6 000 озвученных слов, ~150–300 текстов библиотеки к выходу 1–4급. Нужна внутренняя CMS для методистов с предпросмотром, версионированием и проверкой покрытия лексики.

## 7.4. Этапы разработки

### Этап 0 — Прототип (6–8 недель)
- 0급 целиком (Хангыль, звук, раскладка) — лучшая витрина и тест «вау-эффекта» интерфейса.
- Карточки FSRS + словарь с морфологическим разбором (на базе 기초사전 + Kiwi).
- Кампус-экран и урок-«доска» в черновом виде.
- **Цель:** проверить удержание D1/D7 и реакцию на визуальную концепцию на 50–100 тестерах.

### Этап 1 — MVP «Начальная школа» (4–6 месяцев)
- 0–2급 полностью (TOPIK I): уроки, юнит-тесты, 중간/기말, симуляция TOPIK I.
- Генератор учебного дня, 오답노트, зачётка, посещаемость.
- Перевод со сборкой из блоков, микро-тренажёры (числа, нерегулярные, частицы, вежливость).
- Библиотека: 40–60 текстов 1–2급 + сказки.
- Вступительный тест (экспертная калибровка).

### Этап 2 — «Средняя школа» (6–9 месяцев)
- 3–4급, TOPIK II, письменный стиль, Ханча-граф, 원고지 с проверкой правил.
- ИИ-проверка свободного перевода и письма (51–53).
- Классы 반, взаимопроверка, первые клубы (드라마, K-pop, 비즈니스).
- Калибровка IRT на реальных данных, персональная оптимизация FSRS.

### Этап 3 — «Старшая школа» и ИИ-среда
- 5–6급, задание 54 с ИИ-оценкой по рубрике, публицистика, литература.
- Голосовые ролевые диалоги с иерархией, оценка произношения, TOPIK Speaking.
- KIIP, профессиональные клубы, языковой обмен, корейский интерфейс.

## 7.5. Метрики успеха

| Группа | Метрика | Ориентир |
|--------|---------|----------|
| Обучение | Прирост θ за 30 дней активной учёбы | ≥ 0,25 급 |
| Обучение | Доля сдавших 진급시험 с первой попытки | 60–75% (слишком высокая = экзамен лёгкий) |
| Обучение | **Сдача реального TOPIK** выпускниками (опрос) | Главная внешняя метрика |
| Память | Фактическое удержание vs целевое FSRS | ±2% |
| Вовлечённость | D30 retention / учебных дней в неделю | > 25% / ≥ 4 |
| Качество ИИ | Согласие ИИ-оценки с экспертами | κ ≥ 0,75 |
| Баланс | Доля времени по 4 потокам Nation | каждый 15–35% |

## 7.6. Риски и как их снизить

| Риск | Решение |
|------|---------|
| Жёсткий барьер мастерства отпугивает | Мягкий барьер внутри 급, экстернат, параллельные варианты, 보충수업 вместо «стены» |
| Объём контента огромен | Начать с 0–2급; CMS для методистов; шаблоны упражнений + генерация с ручной проверкой |
| Галлюцинации ИИ в проверке | Эталоны на низких уровнях, гибридный конвейер (правила + морфология + LLM), уверенность, выборочная проверка людьми |
| Стоимость ИИ и речи | Кэширование, лёгкие модели для простых проверок, лимиты в бесплатном тарифе |
| Права на дорамы / вебтуны / новости | Лицензионные партнёрства; до них — собственный контент «в стиле» |
| Плато на 3–4급 | Спирали, клубы, экстенсивное чтение, ощутимый прогноз TOPIK, класс-когорта |
| Перегрузка повторениями FSRS | Автоматический лимит новых карточек по прогнозу нагрузки, режим «каникулы» (방학) с заморозкой |

## 7.7. Монетизация (кратко)

- **Бесплатно:** 0급 целиком, 1급 частично, словарь, базовые карточки.
- **Подписка «Ученик»:** все классы, экзамены, библиотека, тренажёры.
- **«Ученик+»:** ИИ-диалоги, голос, оценка эссе, неограниченная проверка письма.
- **Отдельно:** интенсив-курсы перед датой TOPIK, проверка эссе живым преподавателем.
