# 08. Покрытие грамматики: сверка с Korean Grammar in Use

Сверка программы 0–4급 со списками конструкций учебников *Korean Grammar in Use* (Beginning — уровни 1–2, Intermediate — уровни 3–4) и стандартной программой TOPIK. Полных оглавлений из открытых источников получить не удалось (сайты с разбором уроков недоступны из рабочей среды), поэтому сверка сделана по известному составу учебников. При появлении доступа к оглавлениям — пройтись по таблицам ещё раз.

Обозначения: id урока — `g{класс}-u{юнит}-l{номер}`; **жирным** — уроки, добавленные по итогам сверки.

## Оставлено для 5–6급

Книжные конструкции уровня Advanced: -기 마련이다, -(으)ㄹ 수밖에 없다, -(으)ㄴ/는 셈이다, -에 따라, -(으)로 인해, -(으)나 마나, -는 한, -기에 망정이지, -(으)ㄹ 바에야, -느니, -건 -건 и т. п. Часть из них встречается в текстах 4급 (например, -(으)로 인해 в эссе), но отдельно не объясняется.

## Что ещё не сделано

- -았/었던 vs -던 и -더니 в 3–4급 сравнены, но -더군요 / -던가요 не выделены.
- Частицы 에다가, (이)야말로, 조차, 마저 — уровень 5급.
- Сравнение пар «-아/어서 / -고» и «-는 대로 / -자마자» есть на досках, но отдельного урока-повторения нет.
