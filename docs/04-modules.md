# 4. Модули и тренажёры

Все модули связаны одной **моделью ученика** ([гл. 5](05-algorithms.md)): слово, встреченное в книге, попадает в карточки; ошибка в переводе попадает в 오답노트; освоенная грамматика открывает тексты в библиотеке. Ни один модуль не существует сам по себе.

```
          ┌─────────── Модель ученика (слова, грамматика, навыки, ошибки) ───────────┐
          │                                                                          │
  Словарь ◄──► Карточки FSRS ◄──► Ханча-граф        Библиотека ◄──► Аудио / Видео
     ▲              ▲                                    │               │
     │              │                                    ▼               ▼
  Морфо-разбор ── Грамматика ── Микро-тренажёры ── Перевод КР↔РУ ── ИИ-диалоги ── 원고지
                                       │                                   │
                                       └────────────► 오답노트 ◄────────────┘
```

---

## 4.1. Умный словарь (사전) с морфологическим разбором

**Проблема:** в корейском словаре нет формы 먹었으니까, есть только 먹다. Новичок не может найти слово.

**Решение:**
- Ввод любой словоформы → разбор морфологическим анализатором (Kiwi / MeCab-ko) → цепочка:
  ```
  먹었으니까  =  먹(다) «есть»  +  -었- (прошедшее)  +  -으니까 (причина, «так как»)
                                    ↓ тап                 ↓ тап
                              урок 1급-4              урок 2급-3 (+ сравнение с -아서)
  ```
- Каждое окончание — ссылка на урок грамматики. Если урок ещё не пройден, его можно открыть «в превью».
- Нерегулярные формы восстанавливаются: 들어요 → 듣다 (ㄷ-нерег.) или 들다? Показываем **оба варианта** с вероятностями и контекстом.
- **Статья слова:** значения на русском, уровень (A/B/C, 급), частотность, произношение (с учётом звуковых изменений: 읽다 [익따]), аудио носителя (мужской / женский голос), 3–5 примеров по уровню, Ханча-корень, синонимы/антонимы, коллокации (머리를 감다, а не 씻다), таблица спряжения, регистр (разговорное / письменное).
- **Ввод:** хангыль, «ромаджа»-ввод для тех, у кого нет раскладки (ㅎ→h), рукописный ввод, поиск по русскому, **фото-перевод** (камера → OCR → тап по слову), голосовой ввод.
- **Источник данных:** 한국어기초사전 (NIKL, есть русские переводы, открытая лицензия CC BY-SA) + собственная редактура.

## 4.2. Карточки и запоминание слов (단어장)

- **Планировщик FSRS**, параметры персонализируются после ~1000 повторений.
- **Типы карточек** (по одному слову создаётся несколько):
  1. КР → РУ (узнавание)
  2. РУ → КР с вводом (вспоминание, обязательно для «активного» словаря)
  3. Аудио → значение (аудирование)
  4. **Клоуз в предложении**: «어제 친구를 ___ 기다렸어요» (оч. эффективно: слово + контекст + грамматика)
  5. Произношение: скажи слово вслух → ASR-проверка
  6. Изображение → слово (для конкретной лексики)
- **Не учим слова в изоляции**: новая карточка всегда приходит с предложением из урока или книги, где ученик её встретил («ваше» предложение запоминается лучше).
- **Колоды:** урок (автоматически), библиотека (сохранённые слова), ТОПИК-лексика по уровням, клубы, свои колоды, импорт из Anki (.apkg).
- **Лимиты:** алгоритм ограничивает новые слова, чтобы нагрузка повторений не превышала выбранное время (подробно в [гл. 5](05-algorithms.md)).
- **Мнемоника:** для сложных слов — ИИ-подсказка «ключевым словом» на русском (метод Аткинсона): 바다 «море» → «бадья с морем». Ученик может принять, изменить или отказаться.

## 4.3. Ханча-граф (한자 그래프)

~60% корейской лексики — сино-корейские слова. Знание 300–500 корней резко ускоряет рост словаря на 3–6급.

- **Визуальный граф**: корень в центре (學 학 «учиться»), вокруг — слова (학생, 학교, 학원, 유학, 과학, 대학, 학년), от каждого слова — другие корни (生 생 → 생일, 생활, 학생, 선생님).
- **Режим «угадай значение»**: 「留學」 유학 = 留 «оставаться» + 學 «учиться» → ? → «учёба за границей». Тренирует догадку о новых словах.
- Иероглиф показывается, но **писать его не требуется** (кроме факультатива 한자 동아리). Корейцы сами в основном лишь узнают ханча.
- Омонимичные корни разделены: 수 (水 вода / 手 рука / 數 число / 守 охранять) — частая причина путаницы.
- Порядок изучения по частотности корней в лексике текущего 급, а не по традиционному списку 1800 иероглифов.

## 4.4. Грамматика (문법)

**Устройство урока грамматики:**
1. **Ситуация**: короткий диалог / комикс, где конструкция нужна по смыслу.
2. **Наблюдение**: подсветка формы, вопрос «что общего у этих трёх предложений?»
3. **Правило**: формула присоединения (`V/A + -(으)니까`, отдельно «основа на согласный / гласный / ㄹ»), значение, ограничения.
4. **Ограничения и ловушки** — то, где ошибаются чаще всего («-아서 нельзя с повелительным: ❌ 비가 와서 우산을 가져가세요»).
5. **Контролируемая практика**: трансформация, выбор, клоуз.
6. **Свободная практика**: напиши / скажи о себе.

**Справочник** (помимо уроков):
- Группировка **по смыслу** (как *Korean Grammar in Use*): причина, условие, уступка, намерение, предположение, время, сравнение, перечисление…
- **Сравнительные карточки контрастов**: -아서 vs -(으)니까 vs -기 때문에; 은/는 vs 이/가; -고 있다 vs -아/어 있다; -(으)ㄹ 거예요 vs -(으)ㄹ게요 vs -(으)ㄹ래요. Таблица «можно / нельзя» + 10 упражнений на различение (interleaving).
- **Конъюгатор**: введи глагол → все формы в виде таблицы с подсветкой нерегулярности.
- Каждая конструкция имеет уровень 급, ссылку на задания TOPIK, где она встречалась, и примеры из библиотеки (корпусный поиск).

## 4.5. Тренажёр двустороннего перевода (번역)

| Уровень | КР → РУ | РУ → КР |
|---------|---------|---------|
| 0–1급 | Выбор из вариантов | **Сборка из блоков**: слова-плитки, расставить в SOV + выбрать частицы (частицы — отдельные «прилипающие» плитки) |
| 2급 | Свободный ввод | Блоки + ввод окончаний вручную |
| 3–4급 | Свободный ввод, ИИ-проверка смысла | Свободный ввод, ИИ-проверка: грамматика, частицы, регистр |
| 5–6급 | Перевод абзацев, стиль | Стилистический перевод: «переведи как в новостях» / «как другу» |

**ИИ-проверка** (LLM + правила):
- Принимает **все допустимые варианты** (синонимы, порядок, опущенное подлежащее — в корейском его часто опускают).
- Разделяет ошибки: ❌ грамматическая ошибка, ⚠️ допустимо, но неестественно, 🎭 не тот регистр («так сказали бы другу, а не начальнику»).
- Объяснение на русском + ссылка на урок + запись в 오답노트.
- **Обратная проверка**: после РУ→КР показывается «как сказал бы носитель» в 2–3 вариантах.
- **Ограничение галлюцинаций**: на 0–3급 эталонные ответы задаются вручную, ИИ лишь сопоставляет; полностью свободная ИИ-оценка — с 3급, с отметкой уверенности.

## 4.6. Интерактивная библиотека (도서관)

- **Полки по 급** + фильтр «подходит мне сейчас» (покрытие ≥ 95% по моему словарю, см. [гл. 5](05-algorithms.md)).
- **Жанры**: 전래동화 (сказки: 해님 달님, 흥부와 놀부, 선녀와 나무꾼), адаптированная классика, оригинальные graded readers (сериал с одними и теми же героями от 1 до 4급 — эмоциональная привязка), вебтуны, новости простым языком, эссе, рецепты, тексты песен, сценарии сцен из дорам.
- **Режимы чтения**:
  - Параллельный перевод (колонки / по предложению / по тапу)
  - **Тап по слову** → мини-статья + разбор формы + «в карточки» одной кнопкой
  - **Тап по предложению** → перевод + грамматический разбор
  - Подсветка: новые слова / слова на повторении / знакомые (можно отключить)
  - **Аудиокнига** с караоке-подсветкой и регулировкой скорости (0.75–1.25)
  - **Режим TOPIK**: вопросы на понимание после главы
- **Экстенсивное чтение**: счётчик прочитанных слов (цель — 1 млн за весь курс), статистика «читаю быстрее».
- **Свои тексты**: вставь любой корейский текст / ссылку → приложение разметит его по моему словарю и предложит слова для изучения.

## 4.7. Аудирование и произношение (듣기·발음)

- **Тренажёр минимальных пар**: 불/뿔/풀, 달/딸/탈, 어/오 — на слух, с адаптивной сложностью.
- **Шэдоуинг**: повтори за диктором → визуализация интонационного контура (питч-кривая: моя vs эталон) + ASR-оценка.
- **Диктант (받아쓰기)**: предложение → записать → посимвольная проверка (особенно 받침 и 띄어쓰기).
- **Замедлялка** без искажения тона, повтор фразы, «скрыть субтитры».
- **Голоса**: мужской / женский / пожилой / ребёнок / быстрая речь (как на 3–6급 TOPIK).

## 4.8. Нишевые микро-тренажёры

Каждый — 2–5 минут, режим «блиц», подходит для 쉬는 시간.

| Тренажёр | Суть |
|----------|------|
| **숫자 마스터** (числительные) | Исконные vs сино-корейские в контексте: «3 часа 30 минут» → 세 시 삼십 분; цены 15 800원; возраст 스물다섯 살; даты; телефон. Режим «на слух» |
| **불규칙 도장** (нерегулярные глаголы) | Глагол + окончание → форма за 3 секунды. 돕다+아요=도와요, 모르다+아요=몰라요, 낫다+아요=나아요 |
| **존댓말 엘리베이터** (вежливость) | Одна фраза → «поднять» или «опустить» регистр по этажам: 반말 → 해요 → 합니다 → + 높임 (먹다 → 드시다, 집 → 댁) |
| **조사 퍼즐** (частицы) | Предложения с пропущенными частицами, интерливинг 은/는 · 이/가 · 을/를 · 에/에서 |
| **받침 연음기** (звуковые изменения) | Написанное → как произносится: 국물 [궁물], 신라 [실라], 같이 [가치] |
| **어순 블록** (порядок слов) | Длинное русское предложение → собрать корейское с определительными оборотами |
| **띄어쓰기** | Расставить пробелы (частая ошибка даже у продвинутых) |
| **Counter Shop** | Магазин: посчитай предметы со счётными словами (사과 세 개, 맥주 두 병) |

## 4.9. ИИ-практика и симуляция среды (позже, этап 3)

### Ролевые диалоги с иерархией (역할극)
- **Сценарии** с собеседниками разного статуса: младший друг (반말), бариста (해요), пожилой сосед (해요 + 높임말), начальник (합니다 + 높임말), врач, сотрудник иммиграционной службы, преподаватель вуза.
- Перед диалогом: **цель** («отпросись с работы пораньше, причина — врач») и **проверяемые элементы** (-아/어도 될까요?, 높임말).
- Во время: собеседник реагирует на **нарушение регистра** реалистично («어... 반말하네?» — начальник удивляется), подсказка «선배» по кнопке.
- После: разбор — выполнена ли цель, ошибки, регистр, естественность. Все ошибки → 오답노트.
- **Голосовой режим**: ASR (распознавание корейской речи) → LLM → TTS. Оценка произношения и беглости (темп, паузы).

### Тренажёр письма 원고지 (원고지 연습)
- Интерактивная **разлиновка в клеточку** 20×N, как на бумажном бланке TOPIK.
- Автопроверка **правил 원고지**: отступ в 1 клетку в начале абзаца, знаки препинания в отдельной клетке, две цифры / латинских буквы в одной клетке, точка+кавычка, перенос, пробел в начале строки не ставится.
- Счётчик знаков (задание 53: 200–300; задание 54: 600–700) — с учётом пробелов, как на экзамене.
- **ИИ-оценка по официальной рубрике TOPIK** (내용 및 과제 수행 / 글의 전개 구조 / 언어 사용): баллы по критериям + исправления красным «как учитель» + исправленная версия + «как написал бы на 6급».
- Проверка **стиля**: разговорные формы в эссе (-아/어요, 너무, 그래서 в начале → 따라서) подсвечиваются.
- Шаблоны структуры 서론 → 본론 → 결론 и банк связок по функциям.

### Прочие идеи этапа 3
- **Языковой обмен** с корейцами, изучающими русский (модерация, взаимная проверка).
- **«День в Сеуле»**: цепочка связанных сцен (аэропорт → метро → 편의점 → 병원 → 동사무소) с картой.
- **ИИ-разбор любой сцены** из видео, которое ученик смотрит (загрузка субтитров).
