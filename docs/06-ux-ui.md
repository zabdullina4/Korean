# 6. Интерфейс и визуальная концепция

## 6.1. Большая идея: «Школа, которая живёт в телефоне»

Визуальная метафора — **корейская школа и её мир**: доска, тетрадь в клеточку 원고지, школьный звонок, расписание на стене, школьный двор с сакурой весной и гинкго осенью. Не детская мультяшность, а **тёплая ностальгическая эстетика**, знакомая по дорамам о школе: чистые линии, бумажные текстуры, мягкий свет.

Три правила:
1. **Хангыль — главный герой.** Буквы и слоги — не просто текст, а визуальные объекты: они собираются из черт, светятся при правильном ответе, «падают» в слот.
2. **Каждый экран — предмет из школы.** Словарь — потрёпанный бумажный словарь, тетрадь ошибок — тетрадь с красной ручкой, зачётка — настоящий 성적표 с печатью 도장.
3. **Спокойствие вместо казино.** Никаких мигающих монет и кричащих пушей. Награда — ощущение роста, печать учителя, разблокированное здание кампуса.

## 6.2. Цвет: 오방색 (пять традиционных цветов)

Традиционная корейская палитра 오방색 становится **системой кодирования навыков**. Это одновременно красиво, культурно осмысленно и функционально.

| Цвет | Корейское | Навык / раздел | Значение в традиции |
|------|-----------|----------------|---------------------|
| 🔵 Синий 청 | 靑 | **Аудирование** 듣기 | Восток, весна |
| 🔴 Красный 적 | 赤 | **Речь** 말하기 | Юг, огонь, энергия |
| 🟡 Жёлтый 황 | 黃 | **Чтение** 읽기 | Центр |
| ⚪ Белый 백 | 白 | **Письмо** 쓰기 | Запад, чистый лист |
| ⚫ Чёрный 흑 | 黑 | **Грамматика и лексика** | Север, тушь, основа |

- Цвета **приглушённые, пастельные** в светлой теме (на фоне бумаги 한지 — тёплый кремовый) и **насыщенные на тёмном** в тёмной теме («ночная самоподготовка» — 야간자율학습).
- Акцент для ошибок — **красная учительская ручка** (не системный красный), для успеха — **печать 참 잘했어요** («очень хорошо!» — настоящий штамп корейских учителей начальной школы).

## 6.3. Типографика

- Корейский: **Pretendard** (интерфейс) + **Noto Serif KR / 나눔명조** (тексты книг). Для заголовков-акцентов — каллиграфичный шрифт в стиле кисти.
- Русский: Inter / Golos (пара к Pretendard по метрикам).
- Корейский текст в упражнениях на 15–20% крупнее русского: глаз должен видеть 받침.

## 6.4. Главный экран: кампус (캠퍼스)

Вертикально прокручиваемая **изометрическая карта школьного кампуса**:

```
   ┌─────────────────────────────────────────────┐
   │   🌸  수요일 · 2학기 · 3주차      🔔 출석 47일 │
   │                                             │
   │       [ 6급 ]   ← здания старших классов    │
   │       [ 5급 ]     (в тумане, пока закрыты)  │
   │   [ 4급 ]  [ 3급 ★ ]  ← моё здание светится │
   │      🏫 2급 ✓    📚 도서관   🎭 동아리관      │
   │   🏠 1급 ✓   🌳 운동장 (микро-тренажёры)     │
   │       🚪 예비반 ✓                            │
   │                                             │
   │  ┌───────────── 오늘의 시간표 ─────────────┐ │
   │  │ 조회   단어 복습 · 32       ▶ 7 мин     │ │
   │  │ 1교시  -는 바람에 vs -느라고  12 мин     │ │
   │  │ 2교시  📖 «월급날» гл. 3      10 мин     │ │
   │  │ 3교시  ✍️ перевод 5 фраз      8 мин      │ │
   │  │ 종례   오답노트 · 4           5 мин      │ │
   │  └─────────────────────────────────────────┘ │
   │  [ 🏫 Школа ] [ 📖 Библ. ] [ 📕 Словарь ] [ 👤 ]│
   └─────────────────────────────────────────────┘
```

- **Время суток и сезон** на карте соответствуют реальным (утром — утро, в ноябре гинкго желтеют, в марте — сакура и церемония 입학식). Корейская школьная жизнь чувствуется через смену сезонов.
- Здание текущего 급 «растёт»: каждый сданный юнит зажигает окно. Сданный экзамен = поднят флаг.
- Закрытые классы в лёгком тумане, но **можно зайти в превью** и сдать экстерном.

## 6.5. Ключевые экраны

| Экран | Метафора | Особенность |
|-------|----------|-------------|
| **Урок** | Классная доска (칠판) | Тёмно-зелёная доска, правило «пишется мелом» анимацией; упражнения — на листах, которые кладутся поверх |
| **Карточки** | Стопка 단어장 — карманный блокнот на кольце | Свайп как перелистывание; правильный ответ — карточка «защёлкивается» в кольцо |
| **Сборка предложения** | Слоги-блоки как кубики | Частицы — маленькие «магнитные» плитки, прилипают к слову справа (визуально объясняет агглютинацию) |
| **Словарь** | Бумажный словарь с закладками | Разбор формы — «расслоение» слова на цветные морфемы, разъезжающиеся в стороны |
| **Ханча-граф** | Созвездие на ночном небе | Корни — звёзды, слова — линии между ними; выученные загораются |
| **Библиотека** | Деревянные полки 도서관 | Обложки книг, корешки цветом по 급; «моя полка» прочитанного |
| **Чтение** | Книга с полями | Тап по слову — заметка на полях карандашом |
| **오답노트** | Тетрадь с красными пометками | Записи «закрываются» штампом 해결 |
| **Экзамен** | Бланк TOPIK + OMR-карточка | Реальный вид экзамена; закрашивание кружков; таймер как часы на стене класса |
| **원고지** | Зелёная клетчатая бумага | Буквы встают в клетки; проверка — правки учителя красным |
| **Зачётка** | 성적표 с 도장 | Радар-диаграмма 5 навыков цветами 오방색 |
| **Диалог с ИИ** | Мессенджер, похожий на корейский чат | Аватар собеседника + «индикатор статуса» (младше / равный / старше), подсвечивающий нужный регистр |

## 6.6. Микро-взаимодействия, которые запоминаются

- **Сборка слога из черт**: при правильном вводе слог собирается из штрихов (ㅎ+ㅏ+ㄴ → 한) с лёгкой анимацией кисти.
- **Звонок 학교 종** при смене блока (отключаемый).
- **Печать 도장**: за урок без ошибок — ставится штамп с хрустом бумаги и мягкой вибрацией.
- **Перемена (쉬는 시간)**: экран буквально «выходит во двор» — микро-тренажёры как игры на 운동장.
- **Падение лепестков** при сдаче экзамена; при сдаче 진급시험 — короткая сцена перехода в новое здание.
- **Хаптика** различается: правильный ответ — мягкий «тап», ошибка — двойной лёгкий.

## 6.7. Тон голоса (UX-текст)

- Учитель говорит **на русском, а с ростом 급 — всё больше по-корейски**: на 0–1급 интерфейс полностью русский, на 3급 — инструкции к заданиям на корейском, на 5–6급 можно включить **полностью корейский интерфейс** (погружение).
- Похвала — по-корейски с переводом мелко: «잘했어요! (Отлично!)». Ученик выучивает школьные фразы сам по себе.
- Ошибки никогда не «Неправильно!», а «Почти! Здесь нужна 을, потому что…».

## 6.8. Доступность

- Режим для дальтоников: навыки различаются не только цветом 오방색, но и **иконкой и узором**.
- Динамический размер шрифта, озвучка интерфейса, полностью клавиатурное управление в веб-версии.
- «Тихий режим»: без звука, все аудио-задания заменяются на эквиваленты (для метро).
- Отключение анимаций (prefers-reduced-motion).

## 6.9. Платформы

- **Мобильное приложение** (iOS / Android) — основное: уроки, карточки, тренажёры, чтение.
- **Веб / планшет** — экзамены (большой экран, как на IBT TOPIK), 원고지, длинное чтение, параллельный текст в колонках.
- **Виджеты**: «слово дня», «до экзамена 12 дней», «повторений: 18».
- **Часы**: 1-минутные карточки.
